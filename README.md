# Naturals Signature - Palayamkottai

A single-page website for Naturals Signature, a beauty salon in Palayamkottai.

## Live Site

Deployed on Vercel: https://beauty-website-rose.vercel.app

## Structure

- `index.html` — the complete website (self-contained, no build step required).
- `app/`, `build.gradle.kts`, `gradle/`, etc. — an unrelated Android app scaffold present in this repository.

## Deployment

This is a static HTML site with no build step. It is deployed on [Vercel](https://vercel.com).
